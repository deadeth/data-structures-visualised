# Architecture decision records

Short records of the decisions that shape this repo. Each says what was decided, why, and what it costs. Add a new numbered file when a decision changes; do not rewrite history in an old one, mark it superseded.

| No. | Decision |
| --- | --- |
| 0001 | Static site: Vite, TypeScript, no UI framework, hash routing, GitHub Pages |
| 0002 | Operations record full frames; the player only replays them |
| 0003 | One meaning per colour; magenta is the thing being followed |
| 0004 | Example code is real, runnable and model-checked; frames name its lines |
| 0005 | Steps and code are visible together |
| 0006 | Design pages are data, and the diagram stays simple |
| 0007 | Design quality is judged by blind review rounds |
| 0008 | One sub-agent per page; the coordinator owns shared files |
| 0009 | Mechanisms use the same engine as data structures |
